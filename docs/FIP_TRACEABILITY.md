# FIP Traceability Matrix

Maps every feature in the Feature Implementation Plan (FIP) to where it is
implemented and how it is tested.

- **Where**: the page or URL a user sees, then the code that does the work.
  Paths are relative to the repository root; `file.py:name` is a function or
  class in that file.
- **Tested by**: Django test classes, as `app.tests.ClassName` (run with
  `python manage.py test`). `e2e.*` are the end-to-end journey tests and
  `browser_tests/` the Playwright cross-browser suite (Chromium, Firefox and
  WebKit × desktop and mobile, run with `browser_tests/run.sh`).
- **Status**: **Done** — implemented and covered by automated tests;
  **Done (process)** — delivered as a document/procedure rather than code;
  **Partial** — implemented with a stated limitation; **Not in scope** — not
  built.

The user-facing behaviour of every row is described in
[USER_GUIDE.md](USER_GUIDE.md); the acceptance steps are in
[UAT_CHECKLIST.md](UAT_CHECKLIST.md) (section numbers given as *UAT n.n*).
